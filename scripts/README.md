# scripts/

Вспомогательные скрипты для отладки, разовых проверок и ручной обработки файлов.
На работу бота не влияют. Запускать из корня проекта: `python scripts/<имя>.py`
(скрипты сами добавляют корень в `sys.path`).

## Диагностика БД / файлов

| Скрипт | Назначение |
|---|---|
| `check_db.py` | Быстрая проверка расписания в БД (`data/bot.db`) по группе и дате (зашито вручную внутри). |
| `debug_excel.py` | Диагностика Excel-файла: структура листа, образцы данных. `python scripts/debug_excel.py <путь к файлу>`. |
| `verify_fixes.py` | Проверка исправлений парсера на файлах в БД через `app.scheduler.file_processor`. |

## Ручная обработка / перепарсинг

| Скрипт | Назначение |
|---|---|
| `manual_process.py` | Ручной запуск `check_for_updates` с исправленным парсером + проверка результата в БД. |
| `process_pending.py` | Обрабатывает все файлы с `processed=0` напрямую (без сервисного слоя). |
| `process_pending_files.py` | То же, отдельная реализация обработки необработанных файлов. |
| `reprocess.py` | Перезапуск обработки файлов через `app.parser.processor.process_all_files`. |
| `reprocess_files.py` | Перезапуск обработки через `app.services.file_service.process_all_pending`. |

## Разовые тесты исправлений (исторические)

| Скрипт | Назначение |
|---|---|
| `test_parser.py` | Тесты парсера Excel на конкретных файлах. |
| `test_formatting.py` | Тесты форматирования расписания. |
| `test_all_fixes.py` | Сводная проверка исправлений: парсер кабинетов, время пар, форматирование. |
| `test_final.py` | Финальный тест форматирования расписания с исправлениями. |

Примечание: актуальные тесты проекта лежат в `tests/` — скрипты из этой папки
использовались при разовых отладках и оставлены для истории.
