# Деплой бота на BotHost.ru

## Требования

- Аккаунт на [BotHost.ru](https://bothost.ru)
- Тариф: **Базовый (99₽/мес)** или выше (для persistent storage)
- GitHub-аккаунт (приватный репозиторий)
- Токен бота от [@BotFather](https://t.me/BotFather)
- Telegram ID администратора (можно узнать у [@userinfobot](https://t.me/userinfobot))

---

## Переменные окружения для BotHost

В панели BotHost → **Environment Variables** добавьте:

### Обязательные

| Переменная | Значение | Пример |
|------------|----------|--------|
| `BOT_TOKEN` | Токен от BotFather | `7893506521:AAELZeq...` |
| `ADMIN_IDS` | ID администраторов через запятую | `123456789` или `123456789,987654321` |

### Опциональные (есть дефолты)

| Переменная | Значение | Дефолт | Описание |
|------------|----------|--------|----------|
| `SCHEDULE_PAGE_URL` | URL страницы расписания (факультет Пермская) | `https://pkps-perm.ru/students/raspisanie/fakultet_predprinimatelstva_ul_permskaya_226/` | Страница с Excel-файлами |
| `CHECK_INTERVAL_MINUTES` | Интервал проверки сайта (мин) | `15` | От 5 до 120 минут |
| `LOG_LEVEL` | Уровень логирования | `INFO` | `DEBUG` / `INFO` / `WARNING` / `ERROR` |

## Пошаговая инструкция

### 1. Подключение GitHub к BotHost

1. Откройте [BotHost.ru](https://bothost.ru) → войдите в аккаунт
2. Перейдите в **Settings** → **Integrations**
3. Нажмите **Connect GitHub** → авторизуйте доступ
4. Выберите репозиторий `college-schedule-bot` (или имя вашего репозитория)

### 2. Создание бота в BotHost

1. На главной странице BotHost нажмите **Create Bot**
2. Заполните форму:
   - **Name:** College Schedule Bot (любое название)
   - **Repository:** выберите ваш приватный GitHub-репозиторий
   - **Branch:** `main` (или `master`)
   - **Entry file:** `run.py`
   - **Language:** Python (автоопределится по `requirements.txt`)
   - **Plan:** Базовый (99₽/мес) — **обязательно для persistent storage!**
3. Нажмите **Environment Variables** → добавьте переменные из таблицы выше
4. Нажмите **Create & Deploy**

### 3. Первый запуск

1. Дождитесь завершения сборки (2-3 минуты)
2. Откройте **Logs** → убедитесь, что видите строку:
   ```
   Бот запущен: @your_bot_username
   ```
3. Если есть ошибки — проверьте:
   - `BOT_TOKEN` правильный (скопирован без пробелов)
   - `ADMIN_IDS` содержит только цифры и запятые
   - В логах сборки все зависимости установились успешно

### 4. Проверка работы

#### Базовые команды
1. Откройте бота в Telegram → отправьте `/start`
2. Выберите факультет → курс → группу
3. Проверьте команды:
   - **📍 Сегодня** — должно показать расписание
   - **📆 Завтра** — расписание на следующий день
   - **⚙️ Моя группа** — текущая группа

#### Админ-панель
1. Отправьте `/admin` (только если ваш Telegram ID в `ADMIN_IDS`)
2. Проверьте кнопки:
   - **🔄 Проверить сайт сейчас** — запускает парсинг вручную
   - **👥 Пользователи по группам** — должны показаться username или ID

### 5. Проверка persistent storage (КРИТИЧНО!)

**Это самый важный тест — убедитесь, что данные не стираются:**

1. Выберите группу в боте
2. Перейдите в BotHost → нажмите **Restart** (перезапуск контейнера)
3. Дождитесь, пока бот снова запустится (30-60 сек)
4. Отправьте `/start` боту в Telegram
5. ✅ **Ожидаемый результат:** бот показывает "Вы уже зарегистрированы" и помнит вашу группу
6. ❌ **Если бот просит заново выбрать группу** — persistent storage не работает:
   - Убедитесь, что тариф **Базовый** или выше (на бесплатном данные стираются!)
   - Откройте тикет в поддержку BotHost

### 6. Проверка планировщика

1. Подождите 15-20 минут после запуска
2. Откройте **Logs** → найдите строку:
   ```
   Проверка сайта завершена:
   ✓ Найдено файлов: X
   ✓ Новых файлов: Y
   ```
3. Эта строка должна появляться каждые 15 минут (или по вашему `CHECK_INTERVAL_MINUTES`)

## Обновление бота

После изменения кода:

1. Сделайте commit и push в GitHub:
   ```bash
   git add .
   git commit -m "Описание изменений"
   git push
   ```
2. В BotHost панели нажмите **Deploy** → **Rebuild & Restart**
3. Дождитесь сборки → проверьте логи

## Устранение неполадок

### Бот не запускается

**Проверьте логи сборки:**
- Все ли зависимости из `requirements.txt` установились?
- Нет ли синтаксических ошибок в коде?

**Проверьте логи работы:**
- Правильный ли `BOT_TOKEN`? (ошибка `Unauthorized`)
- Есть ли сообщение "BOT_TOKEN не найден"? → добавьте env-переменную

### База данных стирается при перезапуске

**Причина:** тариф Free (бесплатный) не имеет persistent storage.

**Решение:** переключитесь на тариф **Базовый (99₽/мес)** или выше.

### Админ-панель не открывается

**Проверьте:**
1. Ваш Telegram ID правильно указан в `ADMIN_IDS`?
2. Узнайте свой ID: напишите [@userinfobot](https://t.me/userinfobot)
3. В BotHost → Environment Variables → убедитесь, что `ADMIN_IDS` содержит ваш ID

### Планировщик не работает (нет автопроверки сайта)

**Проверьте логи:**
- Есть ли строка `Планировщик: проверка каждые 15 мин.` при запуске?
- Если планировщик запустился, но проверки не происходят → возможна проблема с timezone

**Временное решение:** используйте кнопку "🔄 Проверить сайт сейчас" в админ-панели для ручной проверки.

## Мониторинг

### Логи в реальном времени

BotHost → **Logs** → **Live Logs** (автообновление)

### Важные строки в логах

| Строка | Значение |
|--------|----------|
| `Бот запущен: @...` | Бот успешно стартовал |
| `База данных готова: sqlite:///...` | База инициализирована |
| `Планировщик: проверка каждые X мин.` | Автопроверка настроена |
| `Проверка сайта завершена` | Парсинг прошёл успешно |
| `ERROR` / `CRITICAL` | Ошибка — требует внимания |
