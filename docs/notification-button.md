# Просмотр расписания из уведомления

С 25.10.2026 уведомления о новом расписании и изменениях содержат inline-кнопку «Посмотреть⬇️».

Кнопка передаёт дату уведомления в существующий обработчик `pickdate:YYYY-MM-DD`. Бот сбрасывает режим ввода даты и отправляет актуальное расписание на этот день для текущей выбранной группы пользователя. Используется обычная отправка расписания с исходным Excel-файлом, кэшем Telegram file_id и сохранением полного текста. Повторное нажатие снова запрашивает данные из БД.

Если группа не выбрана, обработчик предлагает отправить /start. Правила рассылки и определения изменений не меняются. При ограничении частоты Telegram повторная отправка сохраняет кнопку.

Проверка: `python -m pytest tests/ -q` — 62 passed. Тесты проверяют кнопку в обоих типах уведомлений, обработку нажатия через Dispatcher, сброс FSM и повторную отправку после TelegramRetryAfter. Реальный Telegram и рабочая БД в проверках не используются.

После обновления GitHub требуется пересборка в панели BotHost. Кнопка появится в новых уведомлениях; старые сообщения не редактируются.
